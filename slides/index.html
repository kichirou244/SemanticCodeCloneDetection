Semantic Code Clone Detection · POJ-104 · 5 mô hình + MOSS

1 · Bài toán

Hai đoạn code khác chữ, cùng ý nghĩa?

  • Clone Type-1/2: giống hệt / đổi tên biến — dễ bắt
  • Clone Type-3/4: viết lại cấu trúc, đổi thuật toán — rất khó
  • Vấn đề: MOSS (so khớp token) mù trước Type-3/4
  • Mục tiêu: model hiểu ngữ nghĩa, bắt được clone viết lại sâu

2 · Baseline — MOSS (server Stanford)

Nộp code lên Stanford, đọc % khớp

INPUT

2 file mã nguồn nộp lên moss.stanford.edu (qua user id)

XỬ LÝ

Server so khớp, trả report: % khớp mỗi phía (chỉ top match mạnh nhất)

OUTPUT

Điểm = max % hai phía / 100; trên 0,01 là clone; không lọt top = 0 điểm

→

2 · Phương pháp 1 — CodeBERT

Transformer đọc code như văn bản

INPUT

2 đoạn code, tách từ WordPiece, cắt 256 token mỗi phía

XỬ LÝ

Encoder cho vector CLS mỗi phía, ghép [hA; hB; |hA−hB|] qua MLP

OUTPUT

Xác suất clone (sigmoid); trên ngưỡng 0,500 là clone
